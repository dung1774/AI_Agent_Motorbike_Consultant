# Architecture Decision Records

Mỗi ADR ghi **bối cảnh → quyết định → hệ quả → trạng thái**. Chỉ đánh dấu `Chấp nhận` khi team đã chốt; bản khung dưới đây đang ở trạng thái `Đề xuất`.

- [0001 — cách tách frontend và backend](0001-architecture-style.md)
- [0002 — tech stack](0002-tech-stack.md)
- [0003 — cấu trúc repo](0003-folder-structure.md)

Các ADR của nhóm ở `../../docs/decisions/` nằm ngoài phần frontend và được giữ nguyên; nếu cần đối chiếu thì chỉ đọc.
